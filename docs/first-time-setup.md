# First-time setup

The maintained self-hosting guide is [`public/setup-self-host.md`](../public/setup-self-host.md).

Use these supporting documents for the security-sensitive account flows:

- [`owner-setup.md`](owner-setup.md) for permanent-owner bootstrap and recovery;
- [`user-invitations.md`](user-invitations.md) for additional users;
- [`deployment-global-identity.md`](deployment-global-identity.md) for login, sessions, and user-owned credentials;
- [`user-team-sharing-backup-preflight.md`](user-team-sharing-backup-preflight.md) for backup readiness and cutover evidence.

Do not copy commands from older releases. The current product has one deployment-global user directory, invitation-backed account creation, user-owned credentials, private-by-default threads, team sharing, and private R2 objects served only through short-lived signed URLs.
